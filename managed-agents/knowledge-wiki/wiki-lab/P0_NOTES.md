# P0 实施记录与设计差异

本文件记录选择和原因，不修改 `DESIGN.md`。截点固定为 2026-10-15；原件和逐页文字只从本地 `invest-sources` 读取，不下载、不生成额外的原文文字，也不改来源清单或共享证据。

- 元数据：按同一 `source_id` 的 `manifest_record_version` 和 `supersedes_manifest_ref` 构建单链，核对前驱规范化 JSON 的 SHA-256。没有版本字段的初始记录显式记作推定 `m1`。拒绝无链重复版本、分叉、断链、错前驱哈希，以及借元数据修订替换原件。绑定同时保留行号、原始行哈希、规范化记录哈希和整条修订链；不采用文件末行覆盖法。
- 截点按披露日筛选。资料的取得日和元数据修订日可以晚于截点，仍逐条保留，不能因此声称重建了当时已取得的资料状态；本轮也不处理历史截点重建。
- 首次初始集合按披露日、`source_id` 排序分配短号。后续准备复用 `--registry` 时只追加，不重排。三份留出资料不分配初始短号，也不生成抽取块。
- P0 实测是 53 份初始资料：俊知 36 份、长飞 12 份、行业新增 5 份。长飞为五份年报、一份中报、三份公司公告和三份中报点评，逐页文字合计 1,426 页；设计的 13 份 / 1,427 页比目前清单多一份一页，未找到符合指定范围的第十三份，故按实际列示，不凑数。未纳入没有逐页文字的网页/H 股计划/权益披露表及原始接口返回。
- 美银原件和清单均为 9 页，本地已有文字仅 PDF p1–6。P0/P1 不补提取 p7–9，在清单记录缺页，不声称整份研报已读。两份瑞银留出资料也只已有选页：行业为 p1、2、3、4、9、12（PDF 共 25 页）；长飞首次覆盖为 p1–5、7（PDF 共 19 页）。这属于本轮资料范围限制，建议 P2 前确认是否继续保留选页边界。
- 同行中报只取第三节管理层讨论，目录与实际章节边界均已核：亨通 PDF p7–82，中天 p7–26，烽火 p7–13，长芯博创 p10–24。下一页均进入第四节。不扩入后面的分部财务附注；若需要，另作 P2 范围决定。
- 切块按完整 PDF 页序，页内文字不改写。页文字的原始字节另存并逐页哈希；块只增加来源、页序、披露日标记。相邻月报表可整份合块，P1 三份青海公告保持各自独立。实测 P0 为 107 块（100,000 字符上限，单来源各自收尾），高于设计的 75–85 块估计；总字符约 753 万，块数差异主要来自来源之间不任意拼接。P2 成本应按实测块清单估算。
